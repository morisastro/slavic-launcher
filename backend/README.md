# Slavic Launcher — Backend (Node.js + Express + SQLite)

Simple, fast, no Docker, no external database. Deploys on Render in 2 minutes.

## Quick start (local)

```bash
cd backend
npm install
npm start
```

Backend runs at http://127.0.0.1:8090

## Deploy on Render

1. Push to GitHub (already done)
2. Render reads `render.yaml` — auto-detects Node.js service
3. `ADMIN_KEY` is auto-generated by Render

## API

### Public (no auth)

| Method | Route | Description |
|---|---|---|
| GET | `/api/health` | Health check |
| GET | `/api/news` | News feed |
| GET | `/api/servers` | Server list |
| GET | `/api/cosmetics` | Cosmetics catalog |
| POST | `/api/redeem` | Redeem a code `{ code, user }` |
| GET | `/api/user-cosmetics/:uuid` | User's cosmetics |

### Admin (requires `x-admin-key` header)

| Method | Route | Description |
|---|---|---|
| POST | `/api/admin/news` | Create news `{ title, body, date }` |
| DELETE | `/api/admin/news/:id` | Delete news |
| POST | `/api/admin/servers` | Create server `{ name, ip, ... }` |
| DELETE | `/api/admin/servers/:id` | Delete server |
| POST | `/api/admin/cosmetics` | Create cosmetic `{ name, type, ... }` |
| POST | `/api/admin/codes` | Create redeem code `{ code, reward }` |
| GET | `/api/admin/codes` | List all codes |
| GET | `/api/admin/users` | List all users |
