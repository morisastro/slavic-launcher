# Slavic Launcher — Backend (PocketBase)

Free, self-host backend for accounts, cosmetics, news, servers, and redeem codes.
Single Go binary with SQLite — no server cost, runs on your PC.

## Quick start (Windows)

```bat
cd backend
setup.bat
```

That script:
1. Creates a superuser: `admin@slavic.local` / `changeme123` (edit the file to change).
2. Starts PocketBase at http://127.0.0.1:8090.
3. Runs `seed.js` to auto-create the launcher collections.

Then open http://127.0.0.1:8090/_/ and log in with the admin credentials to manage records.

To start it again later (without re-seeding):

```bat
cd backend
start.bat
```

## Collections (created by seed.js)

| Collection | Purpose | Public read |
|---|---|---|
| `users` | Player accounts (from launcher / Discord) | — |
| `cosmetics` | Cosmetic items (cape, hat, emote, …) | yes |
| `user_cosmetics` | Which user owns which cosmetic | — |
| `redeem_codes` | One-time codes that unlock a cosmetic | — |
| `news` | Launcher home news feed | yes |
| `servers` | Featured server list | yes |

## Managing content

- **News, servers, cosmetics, codes** — add/edit in the admin UI or via the REST API:
  `GET /api/collections/news/records`
- **Redeem codes** — generated by the Discord bot (`/code`, `/giveaway`) and read by the launcher's **Rewards** tab.

## Discord bot

See `bot/`:

```bat
cd bot
copy .env.example .env   &:: fill in DISCORD_TOKEN and GUILD_ID
npm install
npm start
```

Commands: `/ping`, `/code <code> <reward>`, `/giveaway`.

## Free hosting (optional, later)

- **PocketBase** — Run on a free tier VM: Render, Fly.io, or Koyeb (use `Dockerfile`).
- Or keep it on your PC for dev/testing — the launcher talks to `http://127.0.0.1:8090`.
- **Backup** — copy `pb_data/data.db`.
- In the launcher, change the URL under **Settings → Backend URL**.
